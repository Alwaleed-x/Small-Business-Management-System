
# 🧾 Small Business Project Management System

A web-based platform designed to help small project owners efficiently manage their operations and meet bank requirements for loan applications.

---

## 📌 Project Overview

This system was developed as part of a university course at the University of Tabuk. Its main purpose is to bridge the gap between small businesses and financial institutions by offering tools to better manage project data, generate necessary documents, and communicate effectively with banks.

---

## 🎯 Objectives

- Provide a user-friendly interface for project management
- Enable project documentation aligned with bank standards
- Streamline communication between entrepreneurs and banks
- Help banks assess loan applications more efficiently
- Empower small businesses with tools for sustainable growth

---

## 👥 User Roles

- **Project Owner**: Manages projects, uploads documents, submits loan applications
- **Bank Representative**: Reviews applications, gives feedback, communicates with project owners
- **Administrator**: Manages users, access control, generates reports, maintains the system

---

## 📐 System Design Highlights

- Use Case Diagrams for each user type
- Activity & Sequence Diagrams to visualize flow
- Conceptual, Logical & Physical database design
- Functional Requirements: project CRUD, document management, user roles
- Non-functional Requirements: security, usability, scalability

---

## 🛠️ Technologies Used

- **Backend**: PHP / phpMyAdmin
- **Database**: MySQL
- **Design**: UML, ERDs
- **Documentation**: Use Case Diagrams, Activity Diagrams, Sequence Diagrams
